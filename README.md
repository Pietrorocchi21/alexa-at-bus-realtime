# Alexa AT Bus Realtime

Skill Alexa personale, ospitata da Alexa con Python, per consultare in futuro i dati realtime ufficiali di Autolinee Toscane.

## Architettura

Alexa -> Alexa-hosted Python -> feed GTFS-RT ufficiali Autolinee Toscane

Nessun VPS, server proprietario, Raspberry Pi, PC sempre acceso o Docker.

## Stato

Repository inizializzato. Nel prossimo commit verranno aggiunti il backend Python e il modello vocale italiano di base.
